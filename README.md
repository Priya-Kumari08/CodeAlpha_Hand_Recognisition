# ✍️ Handwritten Character Recognition System

## 📌 About Project
This project focuses on recognizing handwritten characters (digits or alphabets) using Deep Learning techniques. It uses image processing and Convolutional Neural Networks (CNN) to accurately classify handwritten inputs.

## 🚀 Features
- Recognizes handwritten digits/characters
- Uses Deep Learning (CNN)
- High accuracy on standard datasets
- Easy to train and test

## 🛠️ Technologies Used
- Python
- NumPy
- TensorFlow / Keras
- OpenCV
- Machine Learning & Deep Learning

## 📂 Project Structure
- train.py → Train the CNN model
- predict.py → Predict handwritten character
- main.py → Run the project
- dataset/ → Training dataset (MNIST / EMNIST)
- model.h5 → Trained model
- requirements.txt → Required libraries

## ▶️ How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Train the model:
   python train.py
4. Run prediction:
   python main.py

## 📊 Dataset
- MNIST (Handwritten digits 0–9)
- EMNIST (Alphabets and digits)

## 📈 Model Used
- Convolutional Neural Network (CNN)
